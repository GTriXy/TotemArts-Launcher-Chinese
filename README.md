# Totem Arts Launcher 1.3.0 简体中文汉化版

这是 Totem Arts Launcher 1.3.0 的非官方 Linux AppImage 汉化版。

本项目与 Totem Arts、Electronic Arts 或 Renegade X 官方团队没有隶属关系。AppImage 不包含已安装的游戏文件或用户数据。

## 运行

```bash
chmod +x Totem-Arts-Launcher-1.3.0-cn.AppImage
./Totem-Arts-Launcher-1.3.0-cn.AppImage
```

需要时请安装 FUSE 和 XDelta3。详细说明见 [发布说明-GitHub.md](发布说明-GitHub.md)。
